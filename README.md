# O2C-Enterprise-Order-to-Cash-Integration-Suite
From SAP ABAP DDIC to a **full Order-to-Cash (O2C) enterprise scenario**, business logic in five channels: ABAP programs, OData, SAP Cloud Integration, On-Premise backup (Postgres + SFTP), and a Fiori/UI5 app. Communication goes **in both directions**. **backup** to a Postgres SQL server and On-Premise SFTP server, monitored with Python + FastAPI.
